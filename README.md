# 🟦 Java Exercises Repository 💻📚

## 📖 Descripción  
Este repositorio contiene una colección organizada de **ejercicios prácticos en Java** para reforzar conceptos fundamentales y avanzados del lenguaje.  

Los ejercicios cubren temas como:  
- Programación Orientada a Objetos (POO)  
- Estructuras de datos  
- Algoritmos básicos y recursión  
- Excepciones y más  

Cada ejercicio incluye su enunciado, código fuente comentado y, cuando es posible, casos de prueba.  

---

## 🎯 Objetivos  
- Mejorar la comprensión y aplicación de conceptos de Java.  
- Practicar resolución de problemas y lógica de programación.  
- Prepararse para entrevistas técnicas y proyectos reales.
